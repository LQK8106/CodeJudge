# 整改执行进度报告模板（CodeJudge / zx-learn 通用）

> 用法：复制本文件为 `PROGRESS-<仓库>-<YYYYMMDD>.md` 后填写，**不要直接改本模板**。
> 适用：CodeJudge 的 `docs/quality/EXECUTION-CHECKLIST.md`；zx-learn 的同名清单（任务前缀 `Z`）。
> 填写规则：
> 1. 只填事实与命令输出，不写“基本完成”“大致通过”。
> 2. 状态只有四种：未开始 / 进行中 / 阻塞 / 已完成。
> 3. 任务 ID 必须能在执行清单中查到；新增任务需先在清单登记。
> 4. 结论变化必须附验收命令；没有命令输出的，一律按“未完成”计。
> 5. 不填工期与预计完成时间，只填下一步动作与依赖。

## 附录 D · 常见填写错误

| 错误写法 | 问题 | 正确写法 |
|---|---|---|
| “HTTPS 已基本完成” | 无法判断是否可放行 | “HTTP 301 到 HTTPS；三浏览器 15/15；控制台无混合内容” |
| “压测通过” | 缺少口径 | “同机恒定负载 3 108.8 req/s、0 错误；仍为下界” |
| “缺陷已修复” | 缺少验证 | “新增 3 条断言通过；登录 43/0、鉴权 56/0 不回归” |
| “预计下周完成” | 模板不记录工期 | 改为“下一步：配置证书并复测 SSE” |
| “密钥已更换” | 无法复核 | “旧 token 全 401；硬编码扫描 FAIL 0 / WARN 0” |
