## 5. 局限说明

- **self-preference 风险**：被测语料由 `deepseek-flash`（历史）与 `glm-5.3-flash`（本次补齐）生成，judge 为 `glm-4.5-flash`；judge 与 `glm-5.3-flash` 同属智谱，对同门模型的偏好风险无法完全排除，已用「不同模型 + rubric 固定 + 双次一致性校验」压低，但不等于与人类判断一致。
- **样本量与单轮评测**：40 条、单轮评测，覆盖 5 类判题结论；不足以代表全站题型与语言分布。
- **可执行性只覆盖 Java 代码块**：非 Java 块不执行（记中性 3 分）；编译通过不等于逻辑正确，该维度只回答「代码块本身是否合法」。
- **语料集中在 5 道题**：4001、4002、4007、4008、4011；题目难度与题型有限，结论不能外推到全部题库。
- **`degraded` 口径**：`ai_review` 表没有 `degraded` 列，脚本以 `model in ('degraded','builtin-fallback')` 等价识别模板兜底内容；该映射与 `ReviewService` 的降级标记一致，但缺少库级约束。
- **LLM judge 噪声**：4/5 分边界存在抖动，κ 与一致率只反映两次调用间的稳定性，不反映与人工标注的一致性（本评测未引入任何人工标注）。

## 6. 可直接对外的结论表述（≤3 句）

1. 对 CodeJudge 的 AI 代码点评建立**全自动** LLM-as-Judge 评测：40 条真实点评语料、覆盖 5 类判题结论，4 维 rubric 均分为事实正确性 4.33、可执行性 3.48、相关性 4.4、安全性 4.5（满分 5）。

3. 坏例归为 4 类共 12 条，每类附真实样本 id 与 judge 理由原文，全程零人工打分。
